# 🧟 Paper Autopsy

<h3 align="center">不要读论文，验尸它。</h3>

<p align="center"><a href="README.en.md">English</a> | 中文</p>

**大部分论文很水，几乎全靠包装撑着**；剩下最好的那一小撮成果，也总带着包装。在 AI 盛行的时代，包装本身成了一项低成本、不学就死的科研技术——一个好故事、几张漂亮图表、几个热门关键词的说服力，经常超过实际成果。

而**看穿包装**的能力，是每一个科研者都要交的学费，且这门课从未被正式开设过。初入科研的人抓着摘要和结论当真理，被漂亮图表带偏，把重新定义的问题当成领域难题，在一次又一次"为什么大家都引用这篇？我没看出好在哪"的自我怀疑里摸爬好几年，才慢慢长出第一页就开始追问"证据呢"的直觉。这个学费以年计，交完也不会留下讲义。

Paper Autopsy 想做的，就是把这份讲义写出来：把一个有经验的读者脑子里的判断力，做成一个任何人第一天就能装进工具箱的 agent skill。如果你是老兵，它替你省下例行拆解的时间；如果你是新人，它最重要的作用是示范——每份验尸报告都在展示"一个怀疑的读者是怎么读论文的"，读得多了，那个声音会变成你自己的。

它做的事情用一句话说就是：让 agent 以怀疑为默认立场通读一篇论文，然后给你一份有评级的验尸报告——告诉你**这篇论文剥掉包装之后是什么，而不是它想让你相信什么。**

## 它做什么

给定一篇论文（PDF 路径、arXiv 链接或标题都行），agent 会：

1. **通读全文**，包括正文、图表和附录——摘要只用来记录"作者的自声称"，不作为任何判断的依据；
2. **分析两个动机**：这个领域真实在疼的问题是什么（必要性），以及这个解法是怎么被想出来的（可能性）——这是我们认为是比贡献更本质的东西，详见下文的双动机框架；
3. **在三个维度上评级**（领地 / 思想 / 证据，各 S–D），综合成一句"这篇论文对领域的净贡献"和一条行动建议（精读 / 引用 / 跳过）；
4. **输出一份验尸报告**：每个判断都锚定到论文中的具体位置，锚不住的判断会被降级为"疑似"。

零配置：复制到技能目录即用，之后正常跟 agent 说话就会触发。

不做论文的解释器，做论文的检察官：解释器假设论文值得被理解，检察官要求证据——同一篇论文，两个不同的问题：*"它说了什么？"还是"它实际展示了什么，又仅仅是声称了什么？"*

## 双动机框架

贡献告诉你论文做了什么，**动机告诉你什么是真的**。

**1. 必要性的动机——研究者的领地 🌍**
领域内真实的痛点。它是其他工作也在独立应对的、长期公认的困难——还是为了让方法成立而制造出来的叙事？是领域绕不开的瓶颈，还是"恰好没人这么做"的技术性空隙？领地照见研究者实际立足的领域——以及那里是不是真的在疼。

**2. 可能性的动机——研究者的思想 💡**
这个解法是如何被想出来的？来自一个观察、一次失败模式诊断、一个跨领域类比——还是试错碰运气然后包装成思想？检验方法：每一个非平凡的设计决策，论文给出的是 *why*（可辩护、可证伪）还是只有 *what*（"我们采用…"）？消融实验是窗口：它们在验证核心思想，还是在无关组件上表演？

实验和 benchmark 很重要，但它们是下游——只是检查动机有没有被兑现。动机才是本质。

## 有牙齿的评级

三个维度，各评 S/A/B/C/D，逐级锚定，保证不同的 agent 打出一致的分：

| 维度 | 衡量什么 | S 长什么样 | C/D 长什么样 |
|---|---|---|---|
| **领地** 🌍 | 问题是否真实且重要 | 领域公认的瓶颈，解决它改变领域走向 | 为论文量身制造的叙事 (D) |
| **思想** 💡 | 方法是被理解的还是碰上的 | 思想来源清晰、关键设计有 why、失效边界诚实 | 碰巧有效的技巧被事后神话 (C) |
| **证据** 🔬 | 核心主张是否兑现 | 每个 claim 关键词都有直接证据、最强 baseline 在场、失败诚实呈现 | 结论靠修辞和图表魔术撑着 (C) |

**综合评级不是平均分**——它回答一个问题：*剥掉包装后，这篇论文对领域的真实净贡献是什么？* 领地和思想高而证据不足 = 值得追的未完成工作；证据扎实而思想平庸 = 有用的工程，翻翻即可。

语气跟随评级：真正的好论文会得到明确、具体的盛赞，差论文会被不留情面地抨击——对好论文吝啬赞美，和对差论文吝啬批评一样，都是失职。但每一刀都砍在证据上，砍不到证据上的话会自动降级。

## 内核报告

每次运行以一份结构化的验尸报告收尾——评级打头，然后是领地、思想、论文自声称（刻意放在核查之后，让落差自己显现），以及研究者画像：

> *这位研究者立足于什么样的领地、以什么样的思想方式工作。决定你要不要读他下一篇论文的，是这一点，而不是这一篇。*

每个判断必须锚定到论文中的具体位置（引原文 + 注明章节/图表）。无出处的定性判断会被降级为"疑似"——一份靠感觉写出来的验尸报告，本身就是另一种包装。

**实际产出长什么样？** 看 [examples/attention_report.md](examples/attention_report.md)——一份对 *Attention Is All You Need* 的完整验尸报告（skill 实跑产出，被分析的论文 PDF 也放在同一目录，欢迎逐条对账）。判断一份纯 prompt 产品的唯一方式就是看产出，这是我们的答卷。

## 安装

**方式一：skills.sh CLI（推荐）**

```bash
npx skills add stonebubu/paper-autopsy
```

**方式二：手动复制**

把仓库文件夹复制进你的 agent 技能目录：

```bash
git clone https://github.com/stonebubu/paper-autopsy.git
mkdir -p ~/.agents/skills
cp -r paper-autopsy ~/.agents/skills/paper-autopsy
```

其他 agent 各有各的目录：Claude Code 用 `~/.claude/skills/`，ZCode 用 `~/.zcode/skills/`（优先级高于 `~/.agents/skills/`），项目级安装则放进对应项目目录。

装好之后正常跟 agent 说话就行——丢一个 PDF 路径、arXiv 链接或论文标题，加任何阅读意图（"帮我看看这篇"、"read this paper and tell me what it really shows"），skill 就会触发并走完全部流程。skill 本体以中文写成，但中英文请求都能触发，报告永远用你当前说话的语言书写。

## FAQ

**为什么没有"十种包装手法速查表"之类的 checklist？**
做出强大的 checklist 需要先实际拆解大量论文。这个 skill 有意编码的是*判断力*（双动机框架、评级锚点）而非*枚举*——判断力能推广到没见过的包装形状，checklist 只能抓住已知的那些。

**新人直接用它读论文，会不会失去自己长判断力的机会？**
判断力不是从无菌环境里长出来的，但也不需要靠三年被坑来种疫苗。报告的每个判断都带着证据位置，等于把"资深读者为什么这么判"摊开给你看——你核对一次它的证据链，就是一次练习。风险不是失去成长，而是照单全收；所以请对账，尤其是它跟你直觉不一致的地方。

**你凭什么给别人的论文评级？**
评级不是对作者的审判庭——它是读者的决策工具：把一次完整验尸压缩成一个可执行的"我要不要为这篇论文花掉周末"。每一级标准全部锚定公开、可核查的描述，且每个评级必须挂到论文中的具体证据。不同意，请对证据提出异议，而不是对感觉。

**只支持 ML/AI 论文吗？**
以实证型 ML/AI 论文为主场景设计。流程本身与领域无关；理论论文请把"实验证据"替换为"证明的严密性与假设的合理性"。

**它会为了显得深刻而硬黑好论文吗？**
不会——skill 明确禁止为批判而批判。识别真金与揭穿包装同等重要，语气契约要求顶级评级给出具体、有据的赞美。

**这个 skill 自己会不会出错？**
会。LLM 读论文会幻觉引用、误判 baseline 强弱、被写作质量带偏，本 skill 不免疫于这些。已有的对策是强制证据锚定（每个判断挂原文位置，挂不住就降级措辞），以及逐级锚定的评级标准压制 agent 之间的偏好漂移——但对策不等于免疫。这也是为什么报告永远值得你对账，而不是照单全收。
